# FridgeCam

Ta et bilde av kjøleskapet med mobilen, la AI gjenkjenne innholdet, og få en handleliste basert på hva som mangler.

- **Frontend:** PWA (installerbar web-app, bruker mobilkameraet)
- **Backend:** Kotlin (Ktor), Maven
- **AI:** Vision-modell som returnerer strukturert liste over varer
- **Lagring:** Database for beholdning, faste varer og handleliste

Se [docs/PLAN.md](docs/PLAN.md) for implementasjonsplanen.
